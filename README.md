## Sobre a primeira atividade

Estudo de caso de um sistema de controle de alunos para uma escola:
identificação dos perfis de usuário, definição de requisitos funcionais e não
funcionais, e discussão sobre por que o levantamento precede o
desenvolvimento.

Feita em dupla com [João Pedro Duarte Borges](https://github.com/joaopedroduarteborges).
